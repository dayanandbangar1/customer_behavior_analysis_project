# Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior to identify purchasing patterns, customer segments, product preferences, discount usage, subscription behavior, and revenue trends.

The project demonstrates a complete analytics workflow using Python, SQL, PostgreSQL, and Power BI, supported by a project report and presentation.

---

## 📌 Project Overview

The objective of this project is to analyze customer shopping data and answer important business questions related to:

- Customer spending behavior
- Revenue by customer demographics
- Product performance and customer ratings
- Discount usage
- Customer loyalty and segmentation
- Subscription behavior
- Shipping preferences
- Revenue contribution by age group

The analysis is designed to convert raw customer transaction data into meaningful business insights that can support marketing, customer retention, and product strategy.

---

## 📊 Dataset

The dataset contains **3,900 customer purchase records** with **18 columns**.

### Key Information

- Customer demographics
  - Age
  - Gender
  - Location
  - Subscription Status

- Purchase information
  - Item Purchased
  - Category
  - Purchase Amount
  - Season
  - Size
  - Color

- Shopping behavior
  - Discount Applied
  - Promo Code Used
  - Previous Purchases
  - Frequency of Purchases
  - Review Rating
  - Shipping Type
  - Payment Method

The dataset initially contained missing values in the Review Rating column.

## 🐍 1. Data Analysis using Python

The dataset was first loaded and explored using Pandas.

### Key activities:

- Loaded the dataset using Pandas
- Inspected dataset structure using `info()`
- Generated descriptive statistics using `describe()`
- Checked missing values
- Checked duplicate records
- Standardized column names
- Handled missing Review Rating values
- Created new analytical features

### Feature Engineering

Two important features were created:

- `age_group` – groups customers based on age
- `purchase_frequency_days` – converts purchase frequency into an analytical measure

A data consistency check was also performed between:

- `discount_applied`
- `promo_code_used`

Since the two fields contained redundant information, `promo_code_used` was removed from the cleaned dataset.

## 🗄️ 2. SQL Business Analysis

The cleaned data was loaded into PostgreSQL and analyzed using SQL.

The analysis focused on real-world business questions such as:

### Revenue Analysis

- What is the total revenue generated by male vs. female customers?
- What is the revenue contribution of each age group?

### Customer Behavior

- Which customers used discounts but still spent above average?
- Are repeat buyers more likely to subscribe?

### Product Analysis

- Which products have the highest average review ratings?
- Which products have the highest percentage of discounted purchases?
- What are the top 3 most purchased products within each category?

### Customer Segmentation

Customers were segmented into:

- New
- Returning
- Loyal

based on their previous purchase history.

### Shipping & Subscription Analysis

- Compare average purchase amount between Standard and Express shipping.
- Compare average spending and total revenue between subscribers and non-subscribers.

These SQL questions use techniques including:

- `GROUP BY`
- Aggregate functions
- `CASE`
- Subqueries
- CTEs
- Window functions
- `ROW_NUMBER()`
- `ORDER BY`
- Filtering and conditional aggregation

The complete SQL analysis contains 10 business-focused queries. :contentReference[oaicite:2]{index=2}

## 💡 4. Key Business Insights

The analysis produced several business-focused insights:

The analysis identified New, Returning, and Loyal customer groups based on previous purchases.

### Subscription Behavior

### Product Performance

Based on the analysis, the project proposes:

- **Review Discount Policy** – Evaluate discount usage while maintaining healthy margins.
- **Product Positioning** – Promote highly rated and frequently purchased products.
- **Targeted Marketing** – Focus marketing efforts on high-revenue customer segments.
